# Хроно-Каракули

2D-головоломка о времени на **three.js** в стиле «нарисовано маркером на бумаге в клетку»:
петли времени и призраки, перемотка, замедление, ускорение, стазис, зоны с другим ходом времени (в т. ч. обратным),
**пользовательские уравнения** везде и **редактор уровней**.

## Запуск

```bash
npm start            # python3 -m http.server 8000
# открыть http://localhost:8000
npm test             # тесты ядра (без браузера)
```

three.js лежит в `vendor/` — сборка не нужна, всё на нативных ES-модулях.

## Управление

| Клавиши | Действие |
|---|---|
| `← →` / `A D`, `Пробел`/`W` | бег, прыжок |
| `Shift` | замедлить мир (тратит запас времени) |
| `F` | ускорить мир |
| `R` | перемотка назад |
| `E` | стазис — пузырь заморозки вокруг игрока на 4 с |
| `L` | завершить цикл: прошлая ты становится призраком |
| `Esc` / `Backspace` / `M` | пауза / заново / звук |

**Петля:** когда таймер кончается (или жмёшь `L`), ты возвращаешься на старт, а прошлая ты повторяет свой путь
как призрак — нажимает плиты и держит двери (после конца записи призрак замирает на месте).
Смерть откатывает время на пару секунд назад.

## Уравнения

Любое поведение задаётся формулой — без eval, безопасный компилятор в `src/expr.js`.
Переменные: `t` (локальное время объекта — идёт медленнее/быстрее в зонах), `T` (время цикла), `loop`, `px py pvx pvy`
(игрок), `crystals`, `looplen`, **id плит** (`a && b`), переменные из `defs`, `params` объекта.
Операторы `+ - * / % ^ ! < > <= >= == != && || ?:`, функции `sin cos tan abs sqrt min max clamp lerp fract mod step
smoothstep ease saw tri sq pulse noise rand if …`.

```jsonc
{ "type": "platform", "x": 18, "y": 0, "px": "3.2*sin(t*1.2)" }   // движение по формуле
{ "type": "door",  "open": "a && b" }                              // условие по сигналам плит
{ "type": "zone",  "scale": "1+0.9*sin(w*T)" }                     // ход времени — тоже формула
```

## Формат уровня (`levels/*.json`)

```jsonc
{
  "name": "…", "hint": "…", "loop": 14,                  // loop: длина цикла в секундах (0 — без петли)
  "rules": { "gravity": "34*(2*sq(T,8)-1)", "speed": "7.5", "jump": "13.5", "timeScale": "1", "maxGhosts": 3 },
  "defs":  { "w": "2*pi/6", "wave(a,b)": "a*sin(w*T+b)" },   // свои переменные и функции
  "types": { "pendulum": { "extends": "platform", "params": {"amp": 3},
                           "defaults": { "px": "amp*sin(t*2)" } } },   // свои типы объектов — на JSON
  "entities": [ { "type": "block", "x": 0, "y": -0.5, "w": 10, "h": 1 }, … ]   // x,y — центр, y вверх
}
```

Встроенные типы: `block platform door plate box spikes saw beam zone crystal goal text spawn`.
Новый уровень = новый `.json` + строка в `levels/index.json` (или просто сделай его в редакторе и сохрани в браузере).

## Расширение без правки игры

* **Свой тип в JSON** — `types` + `extends` (см. выше).
* **Плагин** — JS-модуль, подключается через `plugins/index.json` или во вкладке «Плагины» редактора:

```js
export default function (api) {
  api.registerType('fan', {
    label: 'Вентилятор', icon: '✲', defaults: { w: 2, h: 3 },
    update(e, w, dt) {}, sense(e, w, bodies, dt) {}, solid(e, w) {}, hazard(e, w) {},
    draw(e, w, g) { g.rect(e.x, e.y, e.w, e.h, { fill: '#ccc', ink: api.INK }); },
  });
  api.registerFunction('zig', (x) => Math.abs(((x % 2) + 2) % 2 - 1));   // новая функция для формул
}
```

Пример — `plugins/bouncer.js` (батут), он используется в уровне 7. API рисования `g`: `rect circle poly tris line path glow spiral text emit`.

## Редактор

Кнопка «Редактор» в меню (или ✎ на карточке уровня). Мышь: выбор, перетаскивание, ручки изменения размера, рамка,
`Пробел+ЛКМ`/СКМ — панорама, колесо — масштаб. `Del`, `Ctrl+D`, `Ctrl+Z/Y`, стрелки, `Tab` — тест-прогон.
Формулы проверяются на лету, при фокусе показывается график f(t); ползунок «время T» показывает все объекты
в любой момент и рисует траектории пунктиром. Вкладка «Уровень»: правила-формулы, `defs`, `types`.
Сохранение: в браузер, в `.json`, копирование JSON; загрузка файла.

## Устройство

`src/expr.js` язык формул · `src/types.js` реестр типов · `src/sim.js` детерминированная симуляция
(петли, призраки, перемотка по снимкам, зоны, физика) · `src/gfx.js` рендер three.js (рисованные линии,
шейдеры бумаги/акварели, частицы, пост-эффекты времени) · `src/editor.js` редактор · `src/main.js` меню/HUD/ввод.
