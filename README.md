# ⏳ Хроноскетч

Рисованная 2.5D головоломка-платформер о манипуляциях временем на **Three.js**.
Перематывайте время, замыкайте его в петли и командуйте собственными эхо-копиями,
останавливайте мгновения, ускоряйте рост растений и прячьте вещи от самого времени.

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # статическая сборка в dist/ (можно выложить на любой хостинг, base: './')
npm run check-levels   # проверка уровней без браузера: все уровни грузятся и проходятся
```

## Механики времени

| Клавиша | Способность | Что делает |
|---|---|---|
| `R` (держать) | ⏪ Перемотка | Отматывает весь мир назад. Чем дольше держите, тем быстрее. |
| `Q` | ➰ Петля | Время начинается заново, а прошлый вы повторяете каждый свой шаг (эхо). |
| `E` | ⏸ Стоп-кадр | Мир замирает на 3 секунды, вы — нет. |
| `C` | 🐌 Замедление | Переключатель: мир медленнее в 3 раза, пока есть энергия. |
| `F` | ↩ Откат | Мгновенный возврат туда, где вы были 2 секунды назад. |

Законы мира:
- **Золотые объекты** живут вне времени: ни перемотка, ни петли их не возвращают.
- **Эхо** повторяет только ввод. Если мир изменился, эхо может ошибиться: возникает парадокс.
- **Зоны времени**: синие замедляют, оранжевые ускоряют всё внутри, в том числе вас.
- **Ростки** растут вместе с локальным временем: ускорьте их или отмотайте рост назад.
- Эхо можно использовать как ступеньку: встаньте ему на голову.

Управление: `←/→` или `A/D` — бег, `Пробел/W` — прыжок (чем дольше держите, тем выше),
`↓` — рычаг, `↓ + прыжок` — спрыгнуть с доски, `Backspace` — заново, `Esc` — пауза.
Геймпад тоже поддерживается.

## Графика

Весь «рисованный» вид собран из процедурных шейдеров, без единой картинки:
- ступенчатое освещение + штриховка в экранном пространстве (кросс-хэтчинг в тенях);
- «кипящие» чернильные контуры: вершины и линии дрожат с частотой ~7 кадров/с, как в мультфильме;
- контуры только там, где блок граничит с пустотой (маска рёбер в геометрии тайлов);
- бумажное зерно и «топографические» каракули на земле;
- 2.5D: перспективная камера с наклоном, объёмные блоки, параллакс-фон (часы, шестерни, холмы, облака);
- постобработка: VHS-перемотка с сепией и аберрацией, синий монохром стоп-кадра, чернильные шторки;
- персонаж с процедурной анимацией (бег, сжатие-растяжение, моргание, шарф на верле-цепочке);
- частицы, нарисованные во фрагментном шейдере (кляксы, искры, штрихи, песочные часы).

Стрелки гигантских часов на фоне идут **назад**, когда вы перематываете время.

## Редактор уровней

Меню → **Редактор**. Уровень рисуется тем же движком, что и игра.

- ЛКМ — рисовать, ПКМ — стереть, `Shift` + ЛКМ — прямоугольник, колесо — масштаб,
  СКМ или `Пробел` + ЛКМ — двигать камеру, `WASD` — прокрутка.
- `V` — выбор (перетаскивание объектов), `X` — ластик, `1..9` — тайлы, `G` — сетка.
- `Ctrl+Z / Ctrl+Y` — отмена и повтор, `Ctrl+D` — копия, `Delete` — удалить, `Ctrl+S` — сохранить.
- `T` / `Enter` — сразу сыграть. Из теста `Esc` → «Назад в редактор».
- Свойства объектов (каналы, скорость, размеры, «золотой») и настройки уровня (способности,
  петля, размер) правятся в правой панели.
- **Сохранить** кладёт уровень в «Мои уровни» (localStorage), **Экспорт/Импорт** работают с JSON,
  **Ссылка** копирует URL, по которому уровень сразу откроется у другого человека.

**Каналы** связывают механизмы: плита/кнопка/рычаг с каналом `a` открывает дверь с каналом `a`,
двигает платформу, включает зону. `a,b` означает, что должны быть включены оба канала.

## Расширение без переписывания игры

Всё, что умеет игра, регистрируется в реестрах (`src/engine/registry.js`): тайлы, сущности,
способности. Палитра редактора, загрузка уровней и HUD строятся из реестров автоматически.

### Добавить уровень

1. Создайте JSON (в редакторе → «Экспорт» или вручную) и положите его в `public/levels/...`.
2. Впишите путь в `public/levels/index.json`.

Пересобирать игру не нужно: уровни и манифест загружаются во время выполнения.

```jsonc
{
  "name": "Мой уровень",
  "abilities": ["rewind", "stop"],          // rewind, stop, slow, recall + из модов
  "loop": { "duration": 10, "maxEchoes": 2 }, // или null — без петель
  "tiles": [                                  // '#' земля, 'B' кирпич, 'S' камень, 'M' латунь,
    "SSSSSSSSSS",                             // '=' сквозная доска, '^' шипы, '.' пусто
    "S........S",
    "##########"
  ],
  "entities": [                               // x — столбец, y — строка сверху (как в tiles)
    { "type": "player", "x": 1, "y": 1 },     // объект стоит в своей клетке и растёт вправо-вверх
    { "type": "goal", "x": 7, "y": 1 },
    { "type": "crate", "x": 4, "y": 1, "props": { "anchored": true } }
  ]
}
```

### Написать мод

Мод — это ES-модуль с функцией по умолчанию. Пример: `public/mods/springs.js` добавляет
пружины и деревянный тайл, а также пак уровней к ним.

```js
export default function setup(api) {
  const { Entity, registerEntity, registerTile, registerAbility, THREE } = api;

  class Spring extends Entity {
    static state = ['squash'];          // эти поля перематываются и живут в петлях автоматически
    solid() { return { l: this.cx, r: this.cx + 1, b: this.cy, t: this.cy + 0.45 }; }
    onLanded(body) { body.vy = this.props.power; this.squash = 1; } // хук физики
    update(dt) { this.squash = Math.max(0, this.squash - dt * 4); } // dt уже с учётом зон времени
    createView(kit) { /* вернуть THREE.Object3D; kit.sketchMaterial() — рисованный материал */ }
    updateView(view, kit, dt) { /* анимация по состоянию */ }
  }

  registerEntity('spring', {
    cls: Spring,
    editor: { label: 'Пружина', category: 'Мой мод', icon: '🌀',
      props: { power: { type: 'number', default: 18, min: 5, max: 40, label: 'Сила' } } },
  });
}
```

Подключение: впишите путь в `"mods"` в `public/levels/index.json` или в меню **Моды** укажите URL.
В `api` доступны `THREE`, базовые классы `Entity`/`Body`/`Player`, физика (`moveX`, `moveY`,
`overlaps`, `ridersOf`), рисованные материалы (`sketchMaterial`, `addOutline`, `customShader`),
персонаж `Character`, звуки `sfx` и реестры. В консоли браузера тот же объект доступен как `window.Chrono`.

Новая **способность** регистрируется через `registerAbility(id, { name, key, keyLabel, icon, init, onPress, tick, status })`
(см. `src/game/abilities.js`) и включается в уровне через `"abilities"`.

## Устройство кода

```
src/
  engine/      симуляция без графики: реестры, сущности, физика AABB, мир, каналы
  entities/    встроенные тайлы и сущности (игрок/эхо, ящики, двери, платформы, зоны, ростки...)
  game/        Chronos — контроллер времени (история снимков, петли, способности), ввод, HUD, звук
  render/      рисованные шейдеры, тайлы, фон, частицы, персонаж, постобработка
  editor/      редактор уровней
  levels/      загрузка паков, свои уровни, ссылки, моды
public/levels  паки уровней (JSON) + index.json
public/mods    моды
tools/         проверка уровней в Node (npm run check-levels) и записанные решения
```

Симуляция детерминирована и идёт фиксированным шагом 60 Гц. Каждый тик мир сериализуется в снимок
(поля `static state` всех сущностей), поэтому перемотка, петли и откат работают для любых объектов,
включая объекты из модов, без дополнительного кода.
